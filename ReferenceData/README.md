# Route source reference

`start-pin.png` is the original Google Earth starting-point screenshot referenced by the route's metadata. It is retained for provenance and is not bundled in the app.

The other original screenshots are used by the presentation and now have one canonical copy in `Argus/Resources/CampusPhotos`: `boyd-overview.png`, `library-pin.png`, `route-overhead.png`, and `route-oblique.png`. Their embedded source attribution is preserved.

The approximate traced route is `Argus/Resources/Routes/boyd_to_library.geojson`. Its source fields refer to these filenames. Intermediate vertices and entrances are not field verified. The superseded invented route and byte-identical duplicate screenshot copies were removed during cleanup.
